# CuroVex: Explainable AI for Drug Repurposing

## Overview
CuroVex is a research prototype demonstrating an end-to-end computational pipeline for drug repurposing.

## ⚠️ Important: Demonstration Mode
This application runs in **Demo Mode**. All predictions, graph subgraphs, and fidelity metrics are **precomputed and deterministic** to ensure smooth operation on standard hardware without GPU/Neo4j dependencies.

## Installation & Startup
1. Ensure you have Node.js 18+ installed.
2. Extract the `curovex-demo.zip` file.
3. Navigate to the project directory: `cd curovex`
4. Install dependencies: `npm install`
5. Start the development server: `npm run dev`
6. Open [http://localhost:3000](http://localhost:3000) in your browser.

## PWA Installation
In Chrome/Edge: Click the "Install" icon in the URL bar, or go to Chrome Menu > "Install CuroVex".
